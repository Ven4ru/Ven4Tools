# Манифест winget

Заготовка манифеста пакета `Ven4ru.Ven4Tools` для [microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs). Пакет ставит лаунчер (`Ven4Tools.Setup-X.Y.Z.exe`), а тот скачивает и обновляет клиент.

В каталог winget манифест пока **не отправлен**.

## Что проверено (лаунчер 3.9.0)

- `winget validate --manifest installer\winget\Ven4ru.Ven4Tools\3.9.0` — проходит (схема 1.12.0).
- Хеш и адрес установщика совпадают с ассетом релиза `launcher-v3.9.0`.
- Тихое обновление этим установщиком (`/S /UPDATE`) проверено прогоном самообновления. Тихая установка с нуля (`/S`), которой пользуется winget, для 3.9.0 отдельно не проверялась — её проверяет релизный workflow лаунчера.

## Что мешает

`winget install --manifest …` на тестовой машине не завершился: winget помечает скачанный файл как пришедший из интернета, а установщик не подписан, поэтому запуск останавливает окно SmartScreen «Система Windows защитила ваш компьютер». Пока пользователь не нажмёт «Подробнее» → «Выполнить в любом случае», установка стоит. То же окно увидит каждый, кто поставит пакет через winget, пока у файла не накопится репутация или у установщика не появится подпись кода.

## Как отправить

1. Подписать [соглашение участника Microsoft](https://cla.opensource.microsoft.com) — это делает владелец учётной записи лично, один раз.
2. Сделать форк `microsoft/winget-pkgs`, положить папку `Ven4ru.Ven4Tools\3.9.0` в `manifests\v\Ven4ru\Ven4Tools\3.9.0`.
3. Открыть запрос с заголовком `New package: Ven4ru.Ven4Tools version 3.9.0`. В шаблоне запроса пункт «Tested manifest locally with winget install» отмечать только после того, как установка действительно прошла.

## При новом релизе лаунчера

Скопировать папку версии, заменить `PackageVersion`, `DisplayVersion`, `InstallerUrl`, `ReleaseNotesUrl`, `ReleaseDate` и `InstallerSha256` (значение — `setup_sha256` из `version.json` на CDN), затем снова `winget validate`.
