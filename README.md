**Ven4Tools** — бесплатная программа с открытым исходным кодом для автоматической установки популярного софта на Windows. Работает сразу после установки системы — не требует установленного .NET или других компонентов.

  </a>
</p>

<p align="center">

```powershell
$t="$env:TEMP\v4t.ps1";irm ven4tools.ru/install.ps1 -OutFile $t;&$t
```

</p>

При установке launcher можно отдельно выбрать Winget и Chocolatey.
Winget отмечен как рекомендуемый компонент; Chocolatey остаётся
опциональным дополнительным источником. Выбранные компоненты устанавливаются
launcher после первого запуска с подходящими для каждого компонента правами.

<summary>🔮 Куда движется проект — версия 5.0</summary>

<br>

Следующее мажорное обновление — не просто новые функции, а фундамент, на котором дальше проще и быстрее чинить баги и добавлять функции. Вот что изменится и как это почувствуется на практике:

- **Архитектура клиента переведена на MVVM полностью.** Все вкладки избавляются от логики прямо внутри разметки окна и получают собственный слой, покрытый юнит-тестами (уже 500+). Для пользователя это меньше редких «зависших» состояний интерфейса — вроде кнопки, которая не включилась после операции, или статуса, который не обновился: раньше такие баги ловились только вручную, теперь значительная часть логики проверяется автоматически ещё до релиза.
- **Тема оформления — по-настоящему целиком.** Переключатель темы («Тёмная» / «Светлая» / «Бирюзовая» / «Как на сайте») начнёт красить весь интерфейс без исключений. Сейчас часть акцентных элементов (логотип, отдельные кнопки, подписи категорий) закреплена за фирменным зелёным цветом независимо от выбранной темы — в 5.0 это станет последовательным.
- **Фоновая загрузка обновлений Windows.** Режим «уведомлять и скачивать в фоне» на вкладке Windows Update, который сейчас функционально не отличается от «Только уведомлять», получит настоящую фоновую загрузку — патчи будут готовы к установке сразу, без ожидания.

Даты сознательно не фиксируем — качество важнее срока, но прогресс уже сейчас видно в [Issues](https://github.com/Ven4ru/Ven4Tools/issues) и коммитах репозитория.

</details>

## Каталог приложений

- **70+ приложений** в 10 категориях: браузеры, коммуникации, разработка, мультимедиа, утилиты и другие
- **Умная установка**: сначала winget, при недоступности — прямая ссылка
- **Приоритет источников установки**: настройте порядок Winget → прямая ссылка → Chocolatey — глобально или отдельно для каждой категории приложений
- **Проверка доступности** каждого источника — зелёный/красный индикатор в реальном времени
- **Альтернативные источники** для приложений, недоступных в регионе
- **Выбор диска установки** с отображением свободного места
- **Проверка целостности** — SHA256-верификация скачанного файла перед установкой
- **Определение установленных приложений** — уже установленные помечаются автоматически
- **Закреплённые приложения**: до 6 любимых программ выносятся отдельной полосой быстрого доступа над каталогом — установка в один клик
- **Профили каталога**: базовый / расширенный / полный — показывает только нужные приложения
- **Сортировка и фильтры**: скрыть установленные, компактный режим
- **Офлайн-режим и кэш каталога**: каталог загружается по схеме онлайн → локальный кэш → встроенная копия, поэтому программа открывается даже без интернета. В настройках можно включить принудительный офлайн-режим и указать папку для кэширования установщиков

### Поиск и свои приложения

- **Поиск по всем источникам**: если приложения нет в каталоге — под строкой поиска сразу появляются совпадения из двух источников — winget и Chocolatey, сгруппированные по разделам. Выбрал → приложение добавилось в «Пользовательские»
- **Добавление своих приложений** вручную: название, winget ID или прямая ссылка

### Пресеты

- **Сохрани набор приложений** как именованный пресет — один клик и весь список установится заново
- **Экспорт и импорт списка** выбранных приложений в JSON-файл — перенос набора между компьютерами или передача другому человеку

### Избранное

- Отметь любое приложение звёздочкой ★ — включи фильтр «только избранные»

## Windows Update

Вкладка **«Windows Update»** — поиск и установка обновлений самой Windows (не путать с обновлением установленных приложений на вкладке «Установленные»):

- Поиск обновлений всех типов — критичных, security, драйверов, необязательных
- Категоризированный выбор: чекбокс на категории выбирает все патчи внутри, отдельные патчи можно снимать точечно
- Установка выбранных патчей с прогрессом, сводкой по завершении и предложением перезагрузки при необходимости
- Фоновая проверка с выбором режима при первом входе — только уведомлять, либо уведомлять и скачивать в фоне (режим фоновой загрузки в разработке — пока функционально не отличается от «Только уведомлять»)
- Установка никогда не запускается автоматически — только по явному клику

## Лаунчер

Лаунчер — отдельная устанавливаемая программа, которая управляет клиентом Ven4Tools:

- **Установщик с мастером**: устанавливается в `%LOCALAPPDATA%\Ven4Tools\Launcher\`, регистрируется в «Программы и компоненты», появляется в меню «Пуск»
- **Чистый деинсталлятор**: полное удаление через «Программы и компоненты» или меню «Пуск»
- **Скачивание и обновление клиента** — загрузка актуальной версии с проверкой целостности по цепочке источников: CDN (домен) → CDN (прямой IP, в обход DNS) → зеркало на хостинге → GitHub; предпочитаемый источник выбирается в настройках лаунчера, остальные остаются резервом. Если установка сорвалась, предыдущая версия возвращается на место автоматически
- **Установка клиента из локального архива** — кнопка «Установить из файла...» на экране загрузки, когда архив уже лежит на диске: доставлен отдельно, скачан браузером или разворачивается скриптом. Для автоматизации есть режим командной строки `Ven4Tools.Launcher.exe --install-from=<путь> [--silent]`. Подпись архива проверяется офлайн, без обращения к сети; архивы, выпущенные до появления подписи, принимаются по списку ранее опубликованных версий из подписанного `version.json` — для этого нужна сеть, и перед установкой показывается предупреждение
- **Самообновление**: лаунчер сам находит свою новую версию в подписанном `version.json` на CDN (GitHub — резерв, если CDN недоступен) и устанавливает обновление без UAC-запроса
- **Сворачивание в трей** — работает в фоне, всплывающие уведомления о новых версиях клиента
- **Автозапуск с Windows** без запроса прав администратора и **тихий старт** — запуск сразу свёрнутым в трей
- **Проверка компонентов**: winget и Visual C++ Redistributable — обязательные, с предложением установить недостающее; Chocolatey и WebView2 Runtime — опциональные (сам Ven4Tools их не требует)
- **Панель версии**: актуальная версия клиента, дата релиза и список изменений. Старые релизы вручную из списка не выбираются — их zip-ассеты удаляются при ротации; поставить предыдущую версию можно установкой из локального архива (см. выше)
- **Защита URL**: скачивание только с доверенных доменов — GitHub, `cdn.ven4tools.ru`, зеркало `ven4tools.ru/releases/` и домены Microsoft (для компонентов winget). Хост проверяется и до запроса, и по итоговому адресу после редиректов

## Диагностика сети

Вкладка **«Сеть»** позволяет проверить состояние сетевого подключения:

- **Сетевые адаптеры** — список активных интерфейсов с IP-адресами
- **Пинг** — проверка доступности ключевых хостов (1.1.1.1, 8.8.8.8, google.com, ven4tools.ru)
- **Доступность сервисов** — HTTP-проверка Google, YouTube, Discord, Cloudflare, GitHub
- **Внешний IP** — определение публичного IP-адреса через api.ipify.org (резерв — checkip.amazonaws.com)
- **DNS** — проверка разрешения доменных имён
- **Инструменты** — сброс сетевых настроек Windows (netsh winsock reset и др.)

Все проверки этой вкладки — включая ручные — отключаются флажком «Параноидальный режим» в настройках: они обращаются к сторонним хостам и раскрывают им IP-адрес.

## Установка

### Вариант 1: Лаунчер (рекомендуется)

1. Скачайте установщик лаунчера с [ven4tools.ru](https://ven4tools.ru) или из [последнего релиза лаунчера на GitHub](https://github.com/Ven4ru/Ven4Tools/releases?q=launcher-v&expanded=true)
2. Запустите установщик — никаких прав администратора не требуется
3. После установки откройте лаунчер из меню «Пуск» или с рабочего стола
4. Нажмите **«Загрузить Ven4Tools»** — клиент скачается автоматически
5. Нажмите **«Запустить Ven4Tools»**

При выходе новой версии лаунчер уведомит через трей — обновление в один клик.  
Удалить лаунчер можно через «Программы и компоненты» или меню «Пуск».

### Вариант 2: Клиент напрямую

1. Скачайте `Ven4Tools-Client-X.Y.Z.zip` из [последнего релиза](https://github.com/Ven4ru/Ven4Tools/releases/latest)
2. Распакуйте в любую папку
3. Запустите `Ven4Tools.exe` с правами администратора

## Приватность и данные

Аккаунтов нет — регистрация, вход и профиль на сервере не используются. Постоянного идентификатора устройства программа не создаёт и не хранит.

Данные о вашей работе с программой уходят наружу только в трёх случаях, и каждый раз — по явному действию пользователя:

| Что | Когда | Что именно уходит |
|---|---|---|
| Отчёт о сбое (клиент → ven4tools.ru) | Только после ответа «Да» на вопрос при следующем запуске | Версия, версия ОС, тип и текст исключения, стек вызовов, время в UTC, обезличенный хеш идентификатора сеанса. Пути профиля, имя пользователя и имя компьютера заменяются заглушками до отправки |
| Отзыв (клиент → ven4tools.ru) | Только если пользователь сам написал отзыв | Оценка, текст отзыва, версия, канал, время в UTC, тот же обезличенный хеш сеанса. Текст проходит ту же очистку от путей и имён |
| Отчёт о вылете или неудачных установках (лаунчер → GitHub) | Только по кнопке «Создать Issue»/«Отправить»; при включённом «Параноидальном режиме» лаунчер такие отчёты не предлагает вовсе | То же плюс список приложений, которые не установились. Публикуется **публичным** issue в репозитории; время указывается в UTC, часовой пояс не раскрывается |

Идентификатор сеанса случайный, генерируется заново при каждом запуске и между запусками не сохраняется — связать по нему два запуска одного компьютера нельзя.

Всё остальное остаётся на компьютере в `%LOCALAPPDATA%\Ven4Tools` и никуда не отправляется: история установок, избранное, пресеты, настройки, логи. Запись истории отключается флажком на вкладке «История», а сама история удаляется кнопкой «Очистить».

Остальные сетевые обращения персональных данных не содержат, но часть из них выполняется автоматически, без отдельного действия пользователя, и раскрывает сторонним хостам его IP-адрес:

- **загрузка каталога** — `ven4tools.ru`, при недоступности `cdn.ven4tools.ru`, затем `raw.githubusercontent.com`;
- **проверка версий клиента и лаунчера** — CDN и GitHub API (лаунчер);
- **скачивание установщиков** и **проверка обновлений через winget** — сайты производителей и источники winget/Chocolatey;
- **проверка соединения раз в 30 секунд** — HEAD-запрос к `one.one.one.one`, при неудаче TCP-подключение к `8.8.8.8:53`;
- **проверка доступности приложений** при открытии каталога — по HEAD/GET-запросу на сайт производителя каждого приложения каталога;
- **загрузка значков приложений** — с сайтов производителей;
- **автопроверка обновлений Windows** при первом открытии вкладки «Windows Update» — запрос к серверам Microsoft;
- **проверка уведомлений раз в 3 часа** (лаунчер) — подписанный `notifications.json` с `cdn.ven4tools.ru`, при недоступности с `ven4tools.ru`, затем с `raw.githubusercontent.com`.

Флажок «Параноидальный режим» в настройках отключает перечисленные автоматические обращения: проверку соединения, проверку доступности, загрузку значков (индикатор доступности при этом становится серым — «неизвестно»), автопроверку Windows Update при открытии вкладки и фоновую проверку уведомлений в лаунчере. Загрузка каталога и установка приложений продолжают работать всегда; ручная кнопка «Проверить обновления» на вкладке Windows Update режимом не блокируется — это явное действие пользователя, а не фоновая проверка.
