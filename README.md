**Ven4Tools** — бесплатная программа с открытым исходным кодом для Windows 10 и 11. Ставит нужные программы набором из каталога в 138 приложений, убирает лишнее из Windows с возможностью вернуть, помогает с обновлениями Windows, диагностикой и подготовкой к переустановке. Работает сразу после установки системы — не требует установленного .NET или других компонентов. Без рекламы и без аккаунтов.

При установке лаунчера можно отдельно выбрать Winget и Chocolatey. Winget отмечен как рекомендуемый компонент; Chocolatey остаётся
опциональным дополнительным источником. Выбранные компоненты лаунчер устанавливает после первого запуска с подходящими для каждого компонента правами.

## Каталог приложений

- **138 программ в 12 категориях**: браузеры, офис, графика, разработка, ИИ, мессенджеры, мультимедиа, системные, игровые сервисы, драйверпаки, компоненты и другое. Каталог подписан и обновляется без обновления самой программы
- **Режимы каталога**: базовый / расширенный / полный — показывает только нужное
- **Установка набором**: отметил программы — они ставятся по очереди без вопросов. Компоненты ставятся первыми, драйверпаки — последними; уже установленное пропускается
- **Источники установки**: winget, прямая ссылка с официального сайта и Chocolatey. Порядок настраивается глобально или отдельно для каждой категории
- **Проверка целостности**: SHA256-проверка файла, скачанного по прямой ссылке, перед установкой
- **Понятная причина неудачи** по каждому источнику: «Winget: … · Chocolatey: … · Прямая ссылка: …» вместо одной последней ошибки
- **Набор не мешает работать**: окна, которые только что поставленная программа открыла сама, закрываются; зависшая установка прерывается, и набор идёт дальше
- **По желанию — без ярлыков на рабочем столе**: после установки убираются появившиеся ярлыки
- **Проверка доступности** каждого источника и **альтернативные источники** для программ, недоступных в регионе
- **Выбор диска установки** с отображением свободного места
- **Закреплённые приложения**: до 6 программ выносятся полосой быстрого доступа над каталогом
- **Офлайн-режим и кэш каталога**: каталог загружается по схеме онлайн → локальный кэш → встроенная копия, поэтому программа открывается и без интернета

### Поиск и свои приложения

- **Поиск по всем источникам**: если программы нет в каталоге, под строкой поиска появляются совпадения из winget и Chocolatey. Выбрал — программа добавилась в «Пользовательские»
- **Свои программы** вручную: название, winget ID или прямая ссылка

### Наборы

- **Готовые наборы** «Для дома», «Для работы», «Для игр», «Для разработки»
- **Свои наборы** с именем — один клик, и весь список установится заново
- **Набор по коду** вида `V4T:firefox,7zip` и экспорт/импорт списка в JSON — перенос набора между компьютерами
- **Избранное**: звёздочка ★ и фильтр «только избранные»

## Установленные программы

- Список установленного через winget, **обновление** устаревших одним кликом
- **Тихое удаление**: запущенная программа закрывается перед удалением, деинсталляторы без тихого режима отрабатывают молча, программа считается удалённой, только если она действительно исчезла
- Удаляются и программы из профиля пользователя, и записи без пакета winget

## Автоматизация

- **Тихий режим**: `Ven4Tools.exe --install V4T:firefox,7zip --silent` ставит набор без вопросов и завершается с кодом возврата (0 — всё установлено, 1 — часть не установилась, 2 — задание не разобрано, 3 — устанавливать нечего, 4 — клиент уже запущен)
- **Файл ответа**: `Ven4Tools.exe --answer-file набор.json` — список программ, точка восстановления, диск установки и файл итога в одном JSON
- **Параметры**: `--restore-point` / `--no-restore-point`, `--drive D:`, `--report итог.json`, `--offline-cache <папка>`
- **Автообновление программ**: выключено по умолчанию; раз в день или в неделю, со списком исключений. Разово — `Ven4Tools.exe --update-apps --silent`
- **Набор из установленного**: код набора и файл ответа по тому, что уже стоит на компьютере
- **Продолжение после перезагрузки**: незавершённую установку набора клиент предлагает продолжить при следующем запуске
- **Переносной офлайн-набор**: кэш установщиков, копия клиента и файл запуска на флешке — установка на компьютере без интернета

## Windows

### Очистка

**52 действия** — встроенные приложения, реклама и ИИ (Copilot, Recall, виджеты, Bing в поиске, OneDrive), приватность, службы. У каждого действия метка риска «Безопасно / Умеренно / Осторожно» и кнопка «Вернуть»; неподходящее для вашей Windows скрыто. Перед массовыми изменениями создаётся точка восстановления. После обновления Windows «Очистка» показывает, какие из применённых твиков система вернула, и применяет их заново.

### Автозагрузка

Всё, что стартует с Windows, — реестр, папки автозагрузки и задачи планировщика — с издателем и кнопками «Выключить» и «Включить». Ничего не удаляется; записи Windows скрыты и выключаются только после предупреждения.

### Место и файлы

- **Освободить место на диске C**: кэш обновлений, Windows.old, временные файлы, дампы, кэш оптимизации доставки, корзина, эскизы, хранилище компонентов. Удаляется только отмеченное, после подтверждения
- **Кто держит файл**: какие программы не дают удалить или переименовать файл или папку

### Windows Update

Поиск и установка обновлений самой Windows (не путать с обновлением программ в «Установленных»):

- Поиск обновлений всех типов — критичных, безопасности, драйверов, необязательных; выбор по категориям и по отдельным патчам
- Установка выбранного с прогрессом, сводкой и предложением перезагрузки при необходимости
- **Скрыть выбранные** и раздел «Скрытые» с «Вернуть»; перед скрытием обновлений безопасности — предупреждение
- **Не получать драйверы через Windows Update** — чтобы Windows не возвращала старый драйвер поверх нового
- **.NET Framework 3.5** одной кнопкой
- **Ремонт**: проверка системных файлов (DISM и sfc) и сброс Центра обновления
- Фоновая проверка с выбором режима в «Настройках» — только уведомлять или уведомлять и скачивать заранее. Установка никогда не запускается автоматически — только по явному клику

### Office и лицензия

- **Office 365, 2024, 2021, 2019, 2016** скачивается с серверов Microsoft официальным загрузчиком, с выбором языка, и устанавливается без активации
- **«Лицензия»** показывает, активированы ли Windows и Office. Ven4Tools ничего не активирует и не ссылается на инструменты активации: для активации нужен ваш ключ или цифровая лицензия

## Перед переустановкой Windows

- **Набор на флешку**: драйверы этого компьютера (включая сетевой), профили Wi-Fi с паролями, файл ответа с установленными программами каталога и список того, что придётся поставить вручную
- **Возврат одним файлом**: `restore.cmd` из набора на свежей системе возвращает драйверы и Wi-Fi, затем ставит программы
- **Файл ответов для установки Windows** (по желанию): `autounattend.xml` в корень установочной флешки — локальная учётная запись без входа в аккаунт Microsoft и запуск набора при первом входе. Язык, редакцию и диск вы выбираете сами; образ Windows не изменяется

## Диагностика и бенчмарк

- **Сбои за неделю** и **синий экран понятным языком**: название кода, частые причины, что проверить, драйверы, поставленные незадолго до первого сбоя
- **Здоровье дисков**: износ, записано ТБ, температура, наработка, ошибки и вердикт «в норме / следить / сделать резервную копию»
- **Готов ли ПК к Windows 11**: девять требований с подсказкой, как исправить, и срок поддержки Windows 10
- **Батарея ноутбука**: ёмкость от заводской и число циклов
- **Проверка оперативной памяти** штатным средством Windows
- **Intel Turbo Boost**: выбор режима без перезагрузки
- **Датчики и оверлей поверх игр** (эксперимент): видеокарта, диски, загрузка процессора, FPS через Intel PresentMon (ставится по кнопке, подпись Intel проверяется перед каждым запуском). Оверлей ничего не внедряет в игру и сам скрывается, если запущена игра с античитом. Работает без драйвера ядра, поэтому температур процессора пока нет
- **Бенчмарк диска**: скорость, тип подключения и отчёт

## Сеть

- **Сетевые адаптеры** — список активных интерфейсов с IP-адресами
- **Пинг** ключевых хостов (1.1.1.1, 8.8.8.8, google.com, ven4tools.ru) и **доступность сервисов** — HTTP-проверка Google, YouTube, Discord, Cloudflare, GitHub
- **Внешний IP** через api.ipify.org (резерв — checkip.amazonaws.com) и **проверка DNS**
- **Сохранённые сети Wi-Fi**: пароль по кнопке и QR-код, чтобы подключить телефон
- **Сброс сетевых настроек** Windows (netsh winsock reset и др.)

Все проверки этой вкладки — включая ручные — отключаются флажком «Параноидальный режим» в настройках: они обращаются к сторонним хостам и раскрывают им IP-адрес.

## Лаунчер

Лаунчер — отдельная устанавливаемая программа, которая ставит, обновляет и запускает клиент Ven4Tools:

- **Установщик с мастером**: устанавливается в `%LOCALAPPDATA%\Ven4Tools\Launcher\` без прав администратора, регистрируется в «Программы и компоненты», появляется в меню «Пуск». Удаляется там же, полностью
- **Клиент по умолчанию — в `%LOCALAPPDATA%\Programs\Ven4Tools`**. При выборе папки в OneDrive или под защитой Защитника Windows лаунчер предупреждает и предлагает безопасную; «Перенести клиент» копирует его в новую папку со сверкой файлов и перенаправлением ярлыков
- **Скачивание и обновление клиента** с проверкой целостности по цепочке источников: CDN (домен) → CDN (прямой IP, в обход DNS) → зеркало на хостинге → GitHub. Если источник 15 секунд не передаёт данные, лаунчер продолжает со следующего с того же места. Если установка сорвалась, предыдущая версия возвращается автоматически
- **Лимитное подключение**: тихое автообновление ждёт безлимитной сети; ручное работает всегда. Во время установки и обновления компьютер не засыпает
- **Прокси**: «Системный» (с учётными данными Windows) или «Вручную» с проверкой; пароль хранится зашифрованным для вашей учётной записи Windows
- **«Проверить подлинность»**: SHA256 лаунчера и файлов клиента сверяется с опубликованными на CDN и на GitHub, показываются статус подписи манифеста и отпечатки ключей
- **«Диагностика соединения»**: по каждому источнику — DNS, соединение, TLS, скорость, прокси и часы компьютера, итог по-русски и отчёт без имени компьютера и пользователя
- **Если клиент удалил антивирус** или запуск блокирует Smart App Control — лаунчер так и говорит и подсказывает, что делать. Исключения в антивирус он не добавляет никогда
- **Установка клиента из локального архива**: кнопка «Установить из файла...» или `Ven4Tools.Launcher.exe --install-from=<путь> [--silent] [--allow-downgrade]`. Подпись архива проверяется офлайн; архив старее установленной или опубликованной версии ставится только после подтверждения или с ключом `--allow-downgrade`
- **Самообновление**: лаунчер находит свою новую версию в подписанном `version.json` на CDN (GitHub — резерв) и обновляется без запроса UAC; неудачное обновление не проходит молча
- **Трей, автозапуск с Windows и тихий старт** — свёрнутым в трей
- **Проверка компонентов**: winget и Visual C++ Redistributable — обязательные, с предложением установить недостающее; Chocolatey и WebView2 Runtime — опциональные
- **Защита URL**: скачивание только с доверенных доменов — GitHub, `cdn.ven4tools.ru`, зеркало `ven4tools.ru/releases/` и домены Microsoft (для компонентов winget). Хост проверяется и до запроса, и по итоговому адресу после редиректов

## Установка

### Вариант 1: Лаунчер (рекомендуется)

1. Скачайте установщик лаунчера с [ven4tools.ru](https://ven4tools.ru) или из [последнего релиза лаунчера на GitHub](https://github.com/Ven4ru/Ven4Tools/releases?q=launcher-v&expanded=true) — или выполните команду PowerShell выше
2. Запустите установщик — прав администратора не требуется
3. Откройте лаунчер из меню «Пуск» или с рабочего стола
4. Нажмите **«Загрузить Ven4Tools»** — клиент скачается автоматически
5. Нажмите **«Запустить Ven4Tools»**

О новой версии лаунчер сообщит через трей — обновление в один клик.

### Вариант 2: Клиент напрямую

1. Скачайте `Ven4Tools-Client-X.Y.Z.zip` из [последнего релиза](https://github.com/Ven4ru/Ven4Tools/releases/latest)
2. Распакуйте в любую папку
3. Запустите `Ven4Tools.exe` с правами администратора

## Приватность и данные

Аккаунтов нет — регистрация, вход и профиль на сервере не используются. Постоянного идентификатора устройства программа не создаёт и не хранит.

Данные о вашей работе с программой уходят наружу только в трёх случаях, и каждый раз — по явному действию пользователя:

| Что | Когда | Что именно уходит |
|---|---|---|
| Отчёт о сбое (клиент → ven4tools.ru) | Только после ответа «Да» на вопрос при следующем запуске | Версия, версия ОС, тип и текст исключения, стек вызовов, время в UTC, обезличенный хеш идентификатора сеанса. Пути профиля, имя пользователя и имя компьютера заменяются заглушками до отправки |
| Отзыв (клиент → ven4tools.ru) | Только если пользователь сам написал отзыв | Оценка, текст отзыва, версия, канал, время в UTC, тот же обезличенный хеш сеанса. Текст проходит ту же очистку от путей и имён |
| Отчёт о вылете или неудачных установках (лаунчер → GitHub) | Только по кнопке «Создать Issue»/«Отправить»; при включённом «Параноидальном режиме» лаунчер такие отчёты не предлагает вовсе | Версия, ОС, тип и текст ошибки, стек вызовов, список приложений, которые не установились. Публикуется **публичным** issue в репозитории; комментарий пользователя не публикуется; время указывается в UTC |

Идентификатор сеанса случайный, генерируется заново при каждом запуске и между запусками не сохраняется — связать по нему два запуска одного компьютера нельзя.

Всё остальное остаётся на компьютере в `%LOCALAPPDATA%\Ven4Tools` и никуда не отправляется: история установок, избранное, наборы, настройки, журналы, пароли сохранённых сетей Wi-Fi, данные о дисках и батарее. Запись истории отключается флажком на вкладке «История», а сама история удаляется кнопкой «Очистить».

Остальные сетевые обращения персональных данных не содержат, но часть из них выполняется автоматически, без отдельного действия пользователя, и раскрывает сторонним хостам его IP-адрес:

- **загрузка каталога** — `ven4tools.ru`, при недоступности `cdn.ven4tools.ru`, затем `raw.githubusercontent.com`;
- **проверка версий клиента и лаунчера** — CDN и GitHub API (лаунчер);
- **скачивание установщиков** и **проверка обновлений через winget** — сайты производителей и источники winget/Chocolatey;
- **проверка соединения раз в 30 секунд** — HEAD-запрос к `one.one.one.one`, при неудаче TCP-подключение к `8.8.8.8:53`;
- **проверка доступности приложений** при открытии каталога — по HEAD/GET-запросу на сайт производителя каждого приложения каталога;
- **загрузка значков приложений** — с сайтов производителей;
- **автопроверка обновлений Windows** фоном раз в 6 часов — запрос к серверам Microsoft;
- **подсказки поиска в каталоге** — если по набранному тексту в каталоге ничего не нашлось, он передаётся в поиск winget и Chocolatey;
- **проверка уведомлений раз в 3 часа** (лаунчер) — подписанный `notifications.json` с `cdn.ven4tools.ru`, при недоступности с `ven4tools.ru`, затем с `raw.githubusercontent.com`.

По явному действию дополнительно обращаются к сети: скачивание английского языкового пакета при смене языка (`cdn.ven4tools.ru`, `ven4tools.ru`, GitHub), установка Intel PresentMon для счётчика FPS (winget, резерв — CDN Ven4Tools), «Диагностика соединения» и «Проверить подлинность» в лаунчере.

Флажок «Параноидальный режим» в настройках отключает перечисленные автоматические обращения: проверку соединения, проверку доступности, загрузку значков (индикатор доступности при этом становится серым — «неизвестно»), автопроверку Windows Update, подсказки поиска по источникам и фоновую проверку уведомлений в лаунчере. Загрузка каталога и установка приложений продолжают работать всегда; ручная кнопка «Проверить обновления» на вкладке Windows Update режимом не блокируется — это явное действие пользователя, а не фоновая проверка.
